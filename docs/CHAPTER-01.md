## 已核对的数学细节

1. 最高阶导数数组的 `n^k` 个有序分量与 `binomial(n+k-1,k)` 个独立混合偏导分开说明；分类以最高总阶数为准。
2. KdV 为三阶半线性，Burgers 为一阶拟线性；分类表说明线性、半线性、拟线性形式的嵌套关系和特殊参数例外。
3. `p`-Laplacian 的经典展开限于 `Du != 0`，并注明 `1 < p < infinity`、`p=2` 例外、退化和奇异位置。最小曲面主部的两个特征值分别核算。
4. 多孔介质展开限于正解光滑区，区分 `gamma>1`、`0<gamma<1` 与 `gamma=1`；Monge–Ampère 区分 `n=1` 与凸椭圆分支。
5. Fokker–Planck 的漂移符号由 Kolmogorov 算子的形式伴随核对；Maxwell 的散度约束由 `div curl = 0` 保持。
6. Euler / Navier–Stokes 将压力一并视为未知量，注明混合微分阶数；未把不可压系统误称为全部未知量上的一致抛物系统。
7. 热方程差值估计明确边界项为零的依据；该估计只证明所述光滑解类中的唯一性与稳定性，不冒充存在性证明或弱解能量等式的完整证明。
8. 逆时热方程反例使用光滑可解的终端数据，明确在 `L^2` 拓扑下失去连续依赖。
9. Burgers 说明初值及其导数有界、负最小斜率取到时的首次奇性时间；区分幅度有界与梯度爆破。
10. 弱守恒恒等式保留初始项；计算激波的分布系数、Rankine–Hugoniot 速度及压缩方向。一般熵理论留待后章，未声称此处证明了完整适定性定理。
11. Taylor 证明以固定闭球上所有 `k+1` 阶偏导的共同上界控制余项，常数不依赖趋近方向；没有把沿射线的一元估计直接等同于多元一致余项。

这些项目是整理者本轮核算，不是独立审稿。一般椭圆正则性、熵解存在唯一性及 Sobolev / 黏性解理论仅作后续联系，不在本章宣称证明。
