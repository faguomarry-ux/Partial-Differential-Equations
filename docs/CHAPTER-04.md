## 重点展开的证明

1. 分离变量先给出单个模态；无限叠加另证明 L² 收敛、初值恢复和正时间逐项微分，并明确谱基的存在与完备性来自后续理论。
2. Turing 计算区分连续参数下的不稳定区间和实际区域的离散特征值；中性阈值 p = 0 与增长 p < 0 分开。例子的第二模态增长率约 0.421。
3. KdV 衰减条件逐一确定两个积分常数，分别处理上升、下降分支，再直接核验二阶 ODE。双稳态前沿则补出固定横截面、左右分支的严格比较、射击相遇和速度唯一性；使用标准局部稳定／不稳定流形定理作为前提。
4. Barenblatt 解不只在正集内部代入，还检查 u 的零迹与 uᵐ 的零法向通量，说明自由边界不会产生额外集中项；点源初始迹通过缩放和支配收敛恢复。
5. Fourier 统一采用幺正归一化。Plancherel 先用 Gaussian 阻尼和 Fubini，再以 L² 近似单位取极限；反演从 Schwartz 函数扩展，不循环使用尚未建立的结论。
6. Bessel 核先证明可积性；Schrödinger 核使用正实部正则化和平方根分支，区分 L¹ 积分与 L² 乘子解；波能量均分用径向 L¹ 频率积分，避免漏掉一维零端点项。
7. Radon 切片定理展示正交坐标的 Jacobian。一般维带符号极径必须使用绝对值 |r|ⁿ⁻¹；奇维时才等于多项式并变成局部导数。系统的平移参数只代入一次。
8. Cole–Hopf 从消去链式非线性项的 ODE 推出；记录 b = 0 的退化情形、反变换的正性及 Burgers 势函数的时间规范。
9. 速度图与局部 Legendre 变换逐项计算逆矩阵、Hessian 逆及线性方程；说明反演条件、边界条件和跨音速退化不会因线性化而消失。
10. 小扩散先推导管状坐标面积元和 Laplacian，再明确 O(√ε) 余项需要统一导数界；这部分没有声称证明原椭圆 Green 函数的误差估计。
11. Laplace 集中证明包含分母下界、能量间隙和带权尾积分；应用到 Burgers 的指数加权速度，恢复第三章的熵解，并说明多个非退化最低点的加权平均。
12. 驻相证明包含重复分部积分、复 Gaussian 的分支与误差、一个整理者补充的矩阵隐函数 Morse 引理证明，以及分割单位拼接。高频波应用另处理频率截断，避免直接把非紧支集振荡积分套入定理。
13. 均匀化先推导修正子与有效通量，再对对称一致椭圆周期系数补出严格弱收敛证明。两次分部积分把弱乘弱改写为强弱配对；不声称梯度强收敛或全局 O(ε) 误差。
14. CK 证明先确定法向层递推，再逐项核对显式平方根优级数满足比较 PDE，以归纳控制系数；最后说明级数正常收敛、可求导，以及降阶系统各分量确实满足导数相容。解析唯一性由同一递推补出。

## 习题的条件澄清

- 题 1：Aronsson 非仿射例子在轴上不是 C²，解答给出全局黏性接触测试；若要求全局经典解，另指出非零仿射解。
- 题 2：Hadamard 数据在指定一致范数中趋零，而正高度截面上的解范数发散；没有误称每个固定空间点都逐点发散。
- 题 5：快扩散剖面采用标准前向抛物范围 max{0, (n−2)/n} < m < 1。原题字面下界在 n = 1 时容许非正指数，讲义说明此时不能直接沿用正扩散构造；没有把该额外范围的解当作已证明。
- 题 10：不存在对所有 R³ 输入光滑、又转换所有 uₓₜ = 0 解的实函数，常数解即可反驳。给出的对数公式在 u ≠ 0、uₓuₜ > 0 的局部分支上严格核验。
- 题 11–12：Lax 对的谱结论保留共同定义域、光滑特征分支等假设，不把形式微分表达式直接当成完整的算子理论。
- 题 14：依原题仅为 ε 阶的有界余项处理，直接控制两校正的差，不擅自改成 ε² 余项。
- 题 19：沿 x = 0 的时间 Taylor 系数为 (−1)ᵏ(2k)!/k!，由项比直接证明所有非零 t 的级数发散。没有照抄“除原点外都发散”这一会与 t = 0 空间初值级数混淆的说法。
