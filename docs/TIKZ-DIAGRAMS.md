## 使用与编辑

建议先读图注中的模型和条件，再回到相邻公式核对图中的箭头、方向、参数与尺度。尤其注意：热球图是固定时间的权重截面；Dirac 箭头表示质量；驻相阴影表示渐近尺度；Fredholm 图是精确的有限维非对称模型。

正文图通过 config/pde-diagrams.tex 中的 PDEBodyDiagram 接入，边注图通过 PDEMarginDiagram 接入。每幅图单独保存为一个 tikzpicture，可直接编辑点位、公式、颜色及标注。源目录中的 manifest.json 记录插入位置、英文图注与文件关系。

从项目根目录编译，沿用现有 XeLaTeX 配置：

~~~powershell
latexmk -xelatex -halt-on-error main.tex
1..12 | ForEach-Object { latexmk -xelatex -halt-on-error ('chapter-{0:D2}.tex' -f $_) }
python scripts/check-tikz-study-diagrams.py
~~~

校验脚本需要 PyMuPDF，输出 tmp/pdfs/tikz-qa/final-validation.json。它核对图清单、源码接入、编译日志、边注完整性及十二份独立章节与整书逐页文字和坐标；它不代替目视检查或一般数学证明。
